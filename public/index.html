    🎲 Cuotas del partido

    Elige la jornada y escribe las cuotas a mano (mínimo 1,01; vacío = no se ofrece esa opción). El resultado de cada selección se calcula solo cuando pones el resultado en Admin → Calendario (formato «3-1», Real Garra primero).

    📥 Importar cuotas desde JSON

    Pega un JSON con las cuotas de goles de varias jornadas a la vez (anotados, encajados y totales). Solo cambia lo que pongas: el resto de cuotas de esa jornada se queda como está. Si hay algún error no se cambia nada y te dice dónde está.
